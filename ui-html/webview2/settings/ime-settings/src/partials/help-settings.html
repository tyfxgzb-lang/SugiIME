帮助

水杉输入法是一款 Windows 平台的日语输入法。目前支持 Windows 11 / Windows 10 平台。

快速上手

安装输入法后，可以使用 Win + Space 快捷键切换到水杉输入法。默认是日语罗马音输入。

基本功能

支持罗马音与 JIS 假名键盘两种日语输入方案。可在「输入」页切换。F6–F10 可在平假名、全角片假名、半角片假名、全角罗马音、半角罗马音之间转换。模糊音功能可自动纠正浊音/半浊音输入错误。更多功能欢迎自由探索~

实用功能

日语模式下可使用以下快捷键模式：Shift+K 快捷短语、Shift+T 日期时间、Shift+U Unicode 码位、Shift+E Emoji、Shift+M 颜文字、Shift+Y 临时英文。可在「实用功能」页开关各项。
