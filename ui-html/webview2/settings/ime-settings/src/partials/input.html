输入模式
切换中文或日文输入，并保留各模式上次选择的方案
日语方案
罗马音：键入罗马音转换假名；JIS 假名键盘：按 JIS 106 配列每个按键直接对应一个假名（与 ATOK / MS-IME 的假名输入一致）
日文标点
日语模式下输出 、。「」『』 等日文标点；关闭则使用半角标点
F6–F10 假名形态转换
日语输入时，F6 平假名 / F7 全角片假名 / F8 半角片假名 / F9 全角罗马音 / F10 半角罗马音
翻页方式
滚轮翻页依赖系统设置「当我悬停在非活动窗口上方时滚动它们」，该项关闭时滚轮不会到达候选窗口
固定标点
切换中英文时的标点形态，三者互斥
成对标点自动补全
输入左侧符号时自动补全右侧符号，并将光标置于中间
emoji 混输
中文输入时在候选项中加入匹配的 emoji（位于英文候选之后；云候选与 AI 联想会使其相应顺移）
颜文字混输
中文输入时在候选项中加入匹配的颜文字（排在 emoji 之后；云候选与 AI 联想会使其相应顺移）
