实用功能
剪贴板管理
开启后，复制过的文本会显示在表情面板的剪贴板分页中。关闭后立即清空已保存的记录，且只记录文本类型。
快捷短语(K 模式)
日语模式下按 Shift+K，再输入编码即可调用快捷短语
编码只能包含英文字母；触发键 K 不属于编码内容。批量导入格式为：编码短语权重（兼容无权重的两列文件）
No.编码快捷短语权重操作
点击查询后查看快捷短语
导出快捷短语用户词库
日期与时间快捷输入(T 模式)
日语模式下按 Shift+T，再输入 kyou / date 可输入当前日期；输入 jikan / time 可输入当前时间；输入 youbi / week 可输入当前星期。
Unicode 便捷录入(U 模式)
日语模式下按 Shift+U，再输入 Unicode 十六进制码位（可带 +，如 4e00 / +1f600）。空格上屏；Shift+数字选词。
Emoji 快捷输入(E 模式)
日语模式下按 Shift+E，再输入英文关键词即可输入 emoji。例如 laugh。空格上屏；数字选词。
颜文字快捷输入(M 模式)
日语模式下按 Shift+M，再输入英文关键词即可输入颜文字。例如 kiss。空格上屏；数字选词。
临时英文(Y 模式)
日语模式下按 Shift+Y，之后输入的字母按英文处理。空格上屏当前输入；上屏后自动回到原输入。
